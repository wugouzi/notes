* Introduction to CUDA

** Programming Model

*** GPU Hardware Model
        For the purposes of CUDA programming, the GPU can be considered to be a collection of *Streaming
        Multiprocessors* (SMs) which are organized into groups called *Graphics Processing Clusters* (GPCs). Each
        SM contains a local register file, a unified data cache, and a number of functional units that perform
        computations. The unified data cache provides the physical resources for shared memory and L1 cache.
