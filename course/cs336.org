** Linear attention
        Given \(Q,V\in R^{n\times d_k}\), \(K\in R^{n\times d_k}\),
        \begin{equation*}
        Attn(Q,K,V)=\rho(QK^T)V
        \end{equation*}
        This is quadratic due to \(QK^T\) (\(n^2d_k\)), can we do better?

        If \(\rho\) is identity, we can have
        \begin{equation*}
        \rho(QK^T)V=Q(K^TV)
        \end{equation*}
        We have cost \(n^2d_k+n^2d_v\to2nd_vd_k\)

        This looks like a RNN:
        \begin{gather*}
        S_t=\sum_{i\le t} k_tv_t^T\\
        S_t=S_{t-1}+k_tv_t^T \\
        y_t=q_t^TS_t
        \end{gather*}

        Therefore we can save \(S_T\) only need to calculate \(k_tv_t^T\) in each step.

        This ‘duality’ allows us to train efficiently (using the parallel, quadratic form) and inference
        efficiently (using the serial, linear form)
        #+LATEX: \wu{
        In training, we use \((QK^T)V\) and in inference we use \(Q(K^TV)\)
        #+LATEX: }

        Minimax M1 (and minimax-text-01) use a 7-to-1 hybrid (7 linear, 1 full) linear attention.

        Performance (generally) seems strong, and they show linear scaling in context length

** From linear attention to Mamba-2
        we can generalize linear attention a little bit and add per-position weights
        \begin{gather*}
        S_t=S_{t-1}+k_tv_t^T \text{ and }y_t=q_t^TS_t\text{( Linear attention)}\\
        S_t=\gamma_tS_{t-1}+k_tv_t^T \text{ and } y_t=q_t^TS_t+v_t^TD\text{ with }\gamma_t=f(x_t)\text{ (Mamba-2)}
        \end{gather*}

        There is a lot more words to justify this (go read the mamba 2 paper) but the mechanics is that we can
        make linear attention more expressive via gating (gating is good!)

** Gated delta net (and friends)
        Generalize again!
        \begin{gather*}
        S_t=\gamma_t(I-\beta_tk_tk_t^T)S_{t-1}+\beta_tk_tv_t^T\\
        y=q_t^TS_t\text{ with }\gamma_t=f(x_t),\beta_t=f(x_t)
        \end{gather*}

        The gated delta net adds a ‘no input operation’ gate (\(\beta=0\)) And erases anything in the
        direction of the current key (\(I-\beta_tk_tk_t^T\))

        Major challenge: we need sparsity for training-time efficiency…But sparse gating decisions are not
        differentiable!

        Stochastic perturbations
        \begin{gather*}
           G(x)=Softmax(KeepTopK(H(x),k))\\
           H(x)_i=(x\cdot W_g)_i+StandardNormal()\cdot Softplus((x\cdot W_{noise})_i)\\
           KeepTopK(v,k)_i=
           \begin{cases}
           v_i&v_i\text{ is in the top $k$ elements of $v$}\\
           -\infty&\text{otherwise}
           \end{cases}
        \end{gather*}

        1. This naturally leads to experts that are a bit more robust.
        2. The softmax means that the model learns how to rank K experts
        
        Heuristic ‘balancing’ losses:

        system efficiency requires that we use experts evenly

        Deekseek v1-2
        * per-expert balancing - same as the switch transformer
          \begin{align*}
          \call_{ExpBal}&=\alpha_1\sum_{i=1}^{N'}f_iP_i\\
          f_i&=\frac{N'}{K'T}\sum_{t=1}^T\bone(\text{Token $i$ selects Expert $i$})\\
          P_i&=\frac{1}{T}\sum_{t=1}^Ts_{i,t}
          \end{align*}

        * per-device balancing - aggregated by device
          \begin{align*}
          \call_{DevBal}&=\alpha_2\sum_{i=1}^Df_i'P_i'\\
          f_i'&=\frac{1}{\abs{\cale_i}}\sum_{j\in\cale_i}f_j\\
          P_i'&=\sum_{j\in\cale}P_j
          \end{align*}

        Deepseek v3 variation - per-expert bias

        \begin{equation*}
        L_z(x)=\frac{1}{B}\sum_{i=1}^B\left(\log\sum_{j=1}^Ne^{x_j^{(i)}}\right)^2
