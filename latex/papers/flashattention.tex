\section{Introduction}
\label{sec:orgbe273ef}
We propose FlashAttention, a new attention algorithm that computes exact attention with far fewer
memory accesses.

This requires
\begin{enumerate}
\item computing the softmax reduction without access to the whole input
\item not storing the large intermediate attention matrix for the backward pass.
\end{enumerate}

We apply two well-established techniques to address these challenges.
\begin{enumerate}
\item We restructure the attention computation to split the input into blocks and make several passes
over input blocks, thus incrementally performing the softmax reduction (also known as tiling).
\item We store the softmax normalization factor from the forward pass to quickly recompute attention
on-chip in the backward pass, which is faster than the standard approach of reading the
intermediate attention matrix from HBM.
\end{enumerate}

\subsection{An Efficient Attention Algorithm With Tiling and Recomputation}
\label{sec:orgc1cf0a1}
Given \(\bQ,\bK,\bV\in\R^{N\times d}\) in HBM, we aim to compute the attention output
\(\bO\in\R^{N\times d}\) and write it to HBM

Main idea is that we split the inputs \(\bQ,\bK,\bV\) into blocks, load them from slow HBM to fast
SRAM, then compute the attention output w.r.t. those blocks. By scaling the output of each block by
the right normalization factor before adding them up, we get the correct result at the end.

\textbf{Tiling}. Softmax couples columns of \(\bK\), so we decompose the large softmax with scaling. For
numerical stability, the softmax of vector \(x\in\R^B\) is computed as:
\begin{gather*}
m(x):=\max_ix_i\\
f(x):=\left[ e^{x_1-m(x)}\quad\dots\quad e^{x_B-m(x)} \right]\\
l(x):=\sum_if(x)_i\\
softmax(x):=\frac{f(x)}{l(x)}
\end{gather*}
For vectors \(x^{(1)},x^{(2)}\in\R^B\), we can decompose the softmax of the concatenated
\(x=\left[x^{(1)}\;x^{(2)} \right]\in\R^{2B}\)  as
\begin{align*}
m(x)&=m(\left[x^{(1)}\;x^{(2)} \right])=\max(m(x^{(1)}), m(x^{(2)}))\\
f(x)&=\left[ e^{m(x^{(1)})-m(x)}f(x^{(1)})\quad e^{m(x^{(2)})-m(x)}f(x^{(2)}) \right]\\
l(x)&=l(\left[x^{(1)}\;x^{(2)} \right])\\
softmax(x)&=\frac{f(x)}{l(x)}
\end{align*}
Therefore if we keep track of some extra statistics \((m(x),l(x))\), we can compute softmax one block
at a time.

\textbf{Recomputation}. One of our goals is to not store \(O(N^2)\) intermediate values for the backward pass.
The backward pass typically requires the matrices \(\bS,\bP\in\R^{N\times N}\) to compute the
gradients with respect to \(\bQ,\bK,\bV\). However, by storing the output \(\bO\) and the softmax
normalization statistics \((m,l)\), we can recompute the attention matrix \(\bS\) and \(\bP\) easily
in the backward pass from blocks of \(\bQ,\bK,\bV\) in SRAM.

Implementation details: \textbf{Kernel fusion}. Tiling enables us to implement our algorithm in one CUDA
kernel, loading input from HBM, performing all the computation steps (matrix multiply, softmax,
optionally masking and dropout, matrix multiply), then write the result back to HBM

\subsection{Analysis: IO Complexity of FlashAttention}
\label{sec:org3574e78}
\begin{theorem}[]
Let \(N\) be the sequence length, \(d\) be the head dimension, and \(M\) be size of SRAM with
\(d\le M\le Nd\). Standard attention requires \(\Theta(Nd+N^2)\) HBM accesses, while FlashAttention
requires \(\Theta(N^2d^2M^{-1})\) HBM accesses
\end{theorem}

The main idea of the proof is that given the SRAM size of \(M\), we can load blocks of \(\bK\),
\(\bV\) of size \(\Theta(M)\) each. For each block of \(\bK\) and \(\bV\), we iterate over all blocks
of \(\bQ\) to compute the intermediate values, resulting in \(\Theta(NdM^{-1})\) passes over \(\bQ\).
Each pass loads \(\Theta(Nd)\) elements, which amounts to \(\Theta(N^2d^2M^{-1})\) HBM accesses. We
similarly prove that the backward pass of standard attention requires \(\Theta(Nd+N^2)\) HBM accesses
while the backward pass of FlashAttention requires \(\Theta(N^2d^2M^{-1})\) HBM accesses

\begin{proposition}[]
Let \(N\) be the sequence length, \(d\) be the head dimension, and \(M\) be size of SRAM with
\(d\le M\le Nd\). There does not exist an algorithm to compute exact attention with
\(o(N^2d^2M^{-1})\) HBM accesses for all \(M\)in the range \([d,Nd]\)
\end{proposition}

\begin{proof}
Suppose inside SRAM, without IO, we can process \(\abs{R}\) queriess and \(\abs{C}\) keys. Then
\begin{equation*}
\abs{R}+\abs{C}\le\frac{M}{d}
\end{equation*}
Therefore
\begin{equation*}
\abs{R}\abs{C}\le\frac{(\abs{R}+\abs{C})^2}{2}\le\frac{M^2}{2d^2}=\Theta\left(\frac{M^2}{d^2}\right)
\end{equation*}


Now we need to compute \(\frac{N^2}{\abs{R}\abs{C}}\) times, each time we need to load \(M\) data,
therefore we need
\(\Omega(M\cdot\frac{N^2}{M^2/d^2})=\Omega(\frac{N^2d^2}{M})\)
\end{proof}
\subsection{Extension: Block-Sparse FlashAttention}
\label{sec:org438ccd6}
We extend FlashAttention to approximate attention: we propose block-sparse FlashAttention, whose IO
complexity is smaller than FlashAttention by a factor proportional to the sparsity.

Given inputs \(\bQ,\bK,\bV\in\R^{N\times d}\) and a mask matrix \(\tilde{\bM}\in\{0,1\}^{N\times N}\),
we want to compute
\begin{align*}
\bS&=\bQ\bK^T\in\R^{N\times N}\\
\bP&=softmax(\bS\otimes\bone_{\tilde{\bM}})\in\R^{N\times N}\\
\bO&=\bP\bV\in\R^{N\times d}
\end{align*}
We require \(\tilde{\bM}\) to have block from: for some blocks sizes \(B_r,B_c\), for all \(k,l\),
\(\tilde{\bM}_{kl}=\bM_{ij}\) with \(i=\floor{k/B_r}\), \(j=\floor{l/B_c}\) for some
\(\bM\in\{0,1\}^{N/B_r\times N/B_c}\)

\begin{proposition}[]
Let \(N\) be the sequence length, \(d\) be the head dimension, and \(M\) be size of SRAM with
\(d\le M\le Nd\). Block-sparse FlashAttention requires \(\Theta(Nd+N^2d^2M^{-1}s)\) HBM accesses where
\(s\) is the fraction of nonzero blocks in the block-sparsity mask. 
\end{proposition}
